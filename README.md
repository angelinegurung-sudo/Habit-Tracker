# Java CLI Habit Tracker

A very simple habit tracker designed for you to keep your daily habits in check. 

## Features

**ADD feature** : quickly add any new habits you'd like to keep on top of 
**Delete Feature** : get rid of any habits you'd no longer want to track to keep your list clean and organised
**Local storage** : automatically saves your progress to a file in your device so your data doesn't disappear when you close the program

## Tech Stack

* **Language:** Java
* **Storage:** CSV (Comma-Separated Values) via Java File I/O
* **Version Control:** Git & GitHub
